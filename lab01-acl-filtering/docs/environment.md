# 实验环境与地址规划

实验时间：2026-10-17，北京时间。设备内部时间可能显示 UTC，不能与本地记录直接混排。

| 层次 | 本次实际环境 |
|---|---|
| 主机 | Windows 11 |
| Linux | WSL2 Ubuntu，用户 wsl |
| 仿真 | GNS3 2.2 系列，服务器监听 127.0.0.1:3080，启用 API 认证 |
| 虚拟化 | QEMU 8.2.2，KVM |
| 初始路由设备 | CE12800，VRP 8.180，V200R005C10SPC607B607；12 个 e1000 适配器 |
| 最终核心设备 | CHR 7.23.8 long-term；3 个接口；创建模板时设 RAM 256 MB |
| 测试终端 | VPCS 0.8.4 |

| 设备 | 内部接口 | IP |
|---|---|---|
| CHR | ether1 | 192.168.1.1/24 |
| CHR | ether2 | 192.168.2.1/24 |
| CHR | ether3 | 192.168.3.1/24 |
| R2 | GE1/0/0 | 192.168.1.2/24 |
| R2 | GE1/0/1 | 10.0.0.1/24 |
| R3 | GE1/0/0 | 192.168.2.2/24 |
| R3 | GE1/0/1 | 10.0.0.2/24 |
| PC1 | Ethernet0 | 192.168.3.2/24，网关 192.168.3.1 |

CHR 到 10.0.0.0/24 的下一跳为 192.168.1.2；R2、R3 到 192.168.3.0/24 的下一跳分别是 192.168.1.1、192.168.2.1。最终 CHR 路由表已核对，华为配置文件为根据执行记录整理的片段，尚无完整运行配置导出。

辅助 test2 的 192.168.100.2/24 与 R2 内部 GE1/0/2 的 192.168.100.254/24 用于端口映射排查，不属于课件核心四网段。test1 曾用于 VPCS 互通对照。

实验项目目录为 `~/GNS3/projects/Lab2_ACL`，系统镜像目录为 `~/GNS3/images/QEMU`。目录只是本机参考，不要求其他人使用相同用户路径。
