# 参考资料

1. 课程课件《第三章 防火墙技术.pdf》，当前文件 34 个物理 PDF 页。第 1–5 页涉及 ACL 概念、分类、顺序匹配及不同平台默认规则；第 7–21 页涉及反掩码和匹配；第 23–25 页涉及方向与应用；第 29–33 页涉及扩展 ACL。
2. 课程课件《第三章 防火墙技术2.pdf》，当前文件 62 个物理 PDF 页。第 23–27 页涉及部署原则；第 29 页为本次三项“ACL 综合应用（动手）”任务；第 31–61 页为 Quidway ACL；第 61 页给出 firewall packet-filter 应用示例。页码为本次文件中的物理页，不是幻灯片编号。
3. MikroTik，Filter，https://help.mikrotik.com/docs/spaces/ROS/pages/48660608/Filter 。用于核对 forward 链及规则计数器。
4. MikroTik，CHR Installation，https://manual.mikrotik.com/docs/getting-started/installation-and-upgrade/install/chr-installation/ 。
5. MikroTik，CHR Licensing，https://manual.mikrotik.com/docs/getting-started/routeros-licensing/chr/chr-licensing/ 。
6. GNS3 官方设备模板，MikroTik CHR，https://github.com/GNS3/gns3-registry/blob/master/appliances/mikrotik-chr.gns3a 。
7. GNS3 官方 VPCS 项目，https://github.com/GNS3/vpcs 。端口探测命令已在本次 VPCS 0.8.4 中实际执行。

在线资料核对日期为 2026-10-17。生产设备文档不能单独证明某个仿真镜像具备同样命令。课件原文件未随公开仓库复制，提交给教师时可说明已按课程内部材料引用。
